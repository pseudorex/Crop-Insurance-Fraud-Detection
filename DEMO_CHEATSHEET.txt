=================================================================================
                 TOP 5 TEACHER QUESTIONS & HOW TO ANSWER
=================================================================================

Q1: Why use Ganache instead of public Ethereum Mainnet?
ANSWER:
"Ethereum Mainnet requires paying real currency ($) for gas and publicizes all transactions.
For an agricultural insurance consortium, Ganache gives us a private, zero-cost,
enterprise-controlled Ethereum EVM node with instant mining (blockTime = 0), ideal for
high-throughput testing and multi-tenant consortiums."

Q2: What is Gas and why does each operation cost a different amount?
ANSWER:
"Gas is the measure of computational effort on the Ethereum Virtual Machine. It prevents
infinite loops (Halting Problem) and spam attacks. Heavy operations like creating permanent
contract storage (SSTORE) cost 20,000 gas, while read-only functions like verifyClaim
cost 0 gas because they execute locally without modifying blockchain state."

Q3: What happens if a corrupt employee edits the PostgreSQL database directly?
ANSWER:
"They can modify the local SQL row, but they cannot alter the Ethereum blockchain.
When the auditor runs, it re-computes the SHA-256 hash of the modified data and compares
it to the immutable hash stored on Ganache. The hashes mismatch, and the system
immediately flags SECURITY TAMPER DETECTED."

Q4: Why not store all the claim data on the blockchain?
ANSWER:
"For two reasons: Privacy and Cost. Farmers' financial data is legally protected and
competitors shouldn't see each other's customers. Furthermore, storing 200KB of raw JSON
on-chain costs millions of gas, whereas storing a 32-byte SHA-256 hash costs only ~23,000 gas."

Q5: How does the AI model connect to the Blockchain?
ANSWER:
"The DP-XGBoost model infers fraud probability. If the score is >= 0.50 (HIGH),
the system calculates local TreeSHAP feature contributions and calls anchorSHAP() to commit
the explanation hash to the blockchain, creating an immutable audit trail for contested claims."
