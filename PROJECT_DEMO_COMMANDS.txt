================================================================================
  CROP INSURANCE FRAUD DETECTION - PROJECT DEMO COMMANDS
================================================================================

1. RUN END-TO-END AUDIT & TAMPER DETECTION DEMO
--------------------------------------------------------------------------------
Execute the automated end-to-end audit demonstration:
   python blockchain/chain_client.py demo

This executes 5 key phases:
   - Anchors the Federated Global Model M1 hash on-chain
   - Registers a legitimate low-risk claim (LOW risk, no SHAP overhead)
   - Registers a suspicious claim (HIGH risk with anchored SHAP explanation)
   - Verifies cryptographic claim integrity (status: MATCH)
   - Simulates database tampering and catches the mismatch (status: MISMATCH_TAMPERED)


2. REGISTER A CLAIM DIRECTLY
--------------------------------------------------------------------------------
Register a new claim commitment onto the ledger:
   python blockchain/chain_client.py register-claim --claim-id "CLM-2026-LIVE-01" --insurer-id "insurer_1" --farmer-id "FARMER-88401" --net-indemnity 35000.00 --risk-label "LOW" --model-version "M1"


3. VERIFY CLAIM INTEGRITY (TAMPER DETECTION)
--------------------------------------------------------------------------------
Case A: Verify legitimate claim (matches original commitment):
   python blockchain/chain_client.py verify-claim --claim-id "CLM-2026-LIVE-01" --insurer-id "insurer_1" --farmer-id "FARMER-88401" --net-indemnity 35000.00 --risk-label "LOW" --model-version "M1"
   Expected Result: {"valid": true, "status": "MATCH"}

Case B: Tampering test (modified amount from $35,000 to $95,000):
   python blockchain/chain_client.py verify-claim --claim-id "CLM-2026-LIVE-01" --insurer-id "insurer_1" --farmer-id "FARMER-88401" --net-indemnity 95000.00 --risk-label "LOW" --model-version "M1"
   Expected Result: {"valid": false, "status": "MISMATCH_TAMPERED"}

Run federated learning across 6 insurer nodes with L2 gradient clipping and Gaussian noise:
   python ml/federated/train_dp_federated.py
